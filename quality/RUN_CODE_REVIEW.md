## Review Focus Areas

### 1. 계획 정합성

- 변경 내용이 현재 Phase 범위를 넘지 않았는지 확인한다.
- 문서에 없는 신규 구조나 규칙이 생기면 이유가 기록되었는지 확인한다.

### 2. 상태 흐름

- UI 이벤트와 상태 전이가 명확한지 확인한다.
- 상태가 여러 위치에 중복 저장되지 않았는지 확인한다.

### 3. 렌더링 안정성

- 기본 레이아웃이 창 크기 변화나 빈 데이터에서 깨지지 않는지 확인한다.
- Preview, Settings, Logging 같은 보조 패널이 주 흐름을 망치지 않는지 확인한다.

### 4. 오류 처리와 로그

- 경고나 실패가 묵살되지 않았는지 확인한다.
- 추후 분석에 필요한 로그 포인트가 빠지지 않았는지 확인한다.

### 5. 범위 통제

- 필요 이상으로 주식, 거래, 시장 데이터 등 특정 도메인으로 기울지 않았는지 확인한다.
- 현재 단계에 필요한 최소 구조만 도입했는지 확인한다.

## Guardrails

- 파일과 라인 기준으로 구체적으로 지적한다.
- 검증 명령을 확인하지 않았다면 확인하지 않았다고 적는다.
- 하네스 맵이 필요한 변경인데 갱신이 없으면 반드시 지적한다.
